# Projet Guérite — Jalons

Ce repository contient les livrables du projet Guérite, organisés par jalon.

## Jalon 0

Le Jalon 0 contient les 6 maquettes validées comme base de conception :

1. Planning des opérations
2. File de validation
3. Live tracking
4. Fiche conteneur
5. Rapport de shift
6. Paramètres

Les maquettes sont accompagnées d'un index de navigation.

Le développement de l'application définitive commencera après validation du Jalon 0.
