Notes de conception (jalon 0 — phase prototype de démonstration) — Tous les blocs de cet écran (carte, missions, géofences, alertes, filtre véhicule, filtre anomalie, historique, indicateurs de flotte, chauffeurs, planning intégré, données à compléter) lisent désormais un unique objet SIM en JavaScript (source unique de vérité, structurée pour préfigurer un futur connecteur API Trace In). Le référentiel actif de la simulation compte 7 véhicules, exactement ceux positionnés sur la carte : TR-014, TR-021, TR-027, TR-041, TR-055, TR-058, TR-063.

Convention d'identifiant — l'identifiant interne actuel reste TR-xxx ; la convention réelle demandée (Cxxx) n'a pas encore de correspondance confirmée avec ces 7 véhicules et n'a donc pas été devinée. Chaque véhicule porte un champ display_id prêt à recevoir le code Cxxx réel — dès qu'il sera renseigné, tous les blocs de l'écran (carte, filtre, tableaux, alertes, chauffeurs) l'afficheront automatiquement, sans autre changement de code.

Véhicules hors référentiel — TR-009, TR-032 et TR-018 étaient référencés dans les données sources d'origine (missions, présence en géofence, alertes) sans exister sur la carte. Leurs données ne sont pas supprimées : elles sont conservées à part (SIM.outOfScope) pour un futur modèle global, mais n'apparaissent plus comme véhicules actifs de ce Live Tracking tant qu'ils ne rejoignent pas le référentiel de la carte (décision du 30/08/2026).

Les compléments effectués dans « Données à compléter » modifient le référentiel local et temporaire de cette démonstration (état perdu au rechargement de la page) — ce n'est pas une écriture réelle ; dans le produit final, ces actions resteraient dans File de validation, conformément à la règle « couche 4 : une vue, elle n'écrit rien » (cahier des charges Missions/Chauffeurs/Live §7.1). Le temps de présence en géofence applique toujours la règle des 15 minutes. Aucun seuil n'est en dur ; tous restent des paramètres éditables dans l'écran Paramètres (à venir). La carte demeure une représentation schématique des zones — aucune géolocalisation réelle n'est branchée à ce stade ; le simulateur est conçu pour être remplacé, bloc de données par bloc de données, par un vrai connecteur Trace In plus tard, sans changer la façon dont les écrans consomment SIM.
